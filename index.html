READ THE ASSUMPTIONS

Method & boundaries

TRANSPARENT BY DESIGN
01 / Archived model & evaluation

The earlier legacy result used hourly CoinGecko USD samples and a small L2 logistic model. It remains an inspected historical snapshot. Current CoinGecko API terms do not permit using the data for AI model training, so this app does not refresh those archives, retrain the model, calculate new public probabilities or arm new legacy ML accounts.

Saved coefficients, when present, describe only the archived snapshot.

The separate V4 Binance USDT research archive is restricted to personal non-commercial research under CC BY-NC-SA 4.0. It is not connected to this USD account or any real order path.

02 / Existing fills & safe exit

Legacy fills were simulated from sampled public prices. Public new entries are disabled. For a preserved legacy account with an open position, Pause requests liquidation only at a fresh quote whose request and provider timestamps follow the exit decision. If no valid quote arrives, the position stays visibly pending. Optional polling services these exits only.

The V5 prospective price-rule cohort is separate. It starts with a warmup baseline and records only post-start observations; no history is backfilled into its results.

03 / Source, terms & availability

Historical legacy observations and the separate V5 forward price-rule feed use aggregate USD data from CoinGecko ↗. These are sampled prices, not exchange OHLC candles or executable venue quotes. Review the CoinGecko API terms ↗ and license FAQ ↗ before relying on any data workflow.

The default app uses a new local SQLite file; the earlier V3 database is preserved. SQLite content is not encrypted by this app; full-disk encryption is recommended. The V5 paper directory uses restrictive local permissions.

Historical API documentation ↗ · Current price documentation ↗

04 / Synthetic demo & limits

Load the fixed synthetic demo to replay the seeded January 2025 fixture and inspect the legacy simulated ledger. It is not market evidence and never substitutes for public data. Legacy account and snapshot reset controls are disabled in read-only mode.

There is no credential input, real-money switch, exchange-order API, leverage or live execution path in this application.
